# Вычислитель — русскоязычный аналог Wolfram|Alpha для Android

Приложение принимает запрос на русском языке («реши x^2 - 5x + 6 = 0»,
«таблица истинности (x -> y) and not y», «нод 252 105») и показывает результат
блоками: формулы, графики, таблицы. Работает **без интернета**.

## Как устроено

| Часть | Файл | Что делает |
|---|---|---|
| Интерфейс | `app/src/main/java/ru/vychislitel/MainActivity.kt` | Строка ввода, панель символов, WebView |
| Отрисовка | `app/src/main/assets/index.html` | Формулы (MathML), таблицы, графики на canvas |
| Ядро | `app/src/main/python/engine.py` | Разбор русских команд и все вычисления (SymPy) |

Python встроен в APK через [Chaquopy](https://chaquo.com/chaquopy/). Kotlin вызывает
`engine.compute(запрос)`, получает JSON с блоками и передаёт его странице.

## Как собрать

1. Установите **Android Studio** (последнюю версию).
2. Установите **Python 3.12** на компьютер (python.org) и отметьте «Add to PATH».
   Chaquopy использует его во время сборки, чтобы скачать SymPy.
   Если сборка пишет, что Python не найден, раскомментируйте строку `buildPython(...)`
   в `app/build.gradle.kts` и укажите путь к `python.exe`.
3. В Android Studio: **File → Open** → папка `vychislitel`. Дождитесь синхронизации Gradle.
4. Подключите телефон (режим разработчика + отладка по USB) или запустите эмулятор → **Run ▶**.

Первый запуск приложения занимает 10–30 секунд: распаковывается Python и SymPy.
Дальше запросы считаются за доли секунды. APK весит около 40–60 МБ (из-за Python).

## Что умеет

- **Вычисления:** точные и приближённые значения, дроби с периодом, комплексные числа, факториалы.
- **Уравнения и неравенства:** одно уравнение, системы, общие решения тригонометрических уравнений,
  численные корни, если точно не решается.
- **Анализ:** производные (любого порядка, частные), интегралы (неопределённые и определённые
  с закрашенной площадью), пределы (включая односторонние), ряды Тейлора.
- **Графики:** несколько функций, отрезок, разрывы, нажатие показывает координаты.
- **Логика:** таблица истинности, СДНФ, СКНФ, минимальные ДНФ/КНФ, полином Жегалкина, классы Поста.
- **Комбинаторика:** сочетания, размещения, перестановки (в том числе с повторениями).
- **Теория чисел:** НОД/НОК с алгоритмом Евклида и соотношением Безу, разложение на простые,
  делители, функция Эйлера, обратный по модулю, сравнения и китайская теорема об остатках,
  перевод между системами счисления.
- **Рекуррентные соотношения:** формула общего члена и первые члены.
- **Матрицы:** определитель, ранг, обратная, собственные значения и векторы, операции.
- **Статистика:** среднее, медиана, мода, квартили, дисперсии, гистограмма частот.

Полный список примеров — в справке приложения (кнопка «?»).

## Как добавить свою команду

В `engine.py` найдите список `COMMANDS` и добавьте пару «регулярное выражение → функция»:

```python
(_r(r'^квадрат\s+(?P<b>.+)$'),
 lambda res, m: res.expr('Квадрат', parse(m.group('b')) ** 2)),
```

Функция получает объект `res` и добавляет блоки через `res.pod(...)` или `res.expr(...)`.
Ядро можно проверять на компьютере без Android: `pip install sympy`, затем
`python -c "import engine; print(engine.compute('x^2=4'))"` из папки `app/src/main/python`.

## Ограничения

- Нет базы знаний о мире (страны, физические константы, погода) — только математика.
- Нет пошаговых решений, кроме алгоритма Евклида и перевода систем счисления.
- Формулы рисуются через MathML: нужен WebView на Chromium 109+ (обновляется через Google Play).
  На старых устройствах вместо красивых формул будет обычный текст.
